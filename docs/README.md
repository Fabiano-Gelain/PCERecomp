# Documentation

- [hardware/INDEX.md](hardware/INDEX.md) — **hardware documentation index**: what exists, where it came
  from, which source is the most reliable and the known gaps.
- [../tools/trace/README.md](../tools/trace/README.md) — trace, comparison and image tools.

Check `hardware/INDEX.md` before implementing any part of the hardware. Without documentation it is easy
to "invent" details, which is the most common mistake in this kind of project.
