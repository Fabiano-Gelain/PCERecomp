# Hardware documentation index

Check this index before implementing any part of the hardware.
Trust order: **Geargrafx code / Mesen tests** > text documents > summarized notes.
The text documents are old (1990s–2000s) and sometimes incomplete. When they conflict, the behavior
of Geargrafx (`reference/Geargrafx/src/`) is the reference.

## Local references in `reference/` (not in Git; see "How to restore")

| Folder | What it is | Use it for |
|---|---|---|
| `reference/Geargrafx/` | PC Engine emulator in C++ (GPL-3), very readable, supports HuCard, CD-ROM², Arcade Card | Exact behavior of everything. Key files in `src/`: `huc6280*` (CPU, timing, PSG), `huc6270*` (VDC), `huc6260*` (VCE), `cdrom*`, `adpcm*`, `memory*`, `input*` |
| `reference/mednafen_src/` | Mednafen 1.32.1 source code (GPL-2). Only `mednafen/src/pce/pcecd.cpp` and `mednafen/src/cdrom/scsicd.cpp` extracted | **Second opinion** when Geargrafx and the real game/Mednafen disagree. Already used for: CD volume fade (`runtime/cd/cdrom.h`) |
| `reference/huc6280-tests/` | Automatic HuC6280 instruction tests generated by Mesen (MIT). 256 files `v1/XX.json.bin`, one per opcode; `transcode_json.py` converts them to JSON | Validating the interpreter (`tests/cpu`) |

**License:** Geargrafx is GPL-3 and this project is MIT. Use it as a reference for behavior; do not copy
its code. Only `tools/reference_trace`, which links Geargrafx to produce reference traces, is GPL-3.

### How to restore `reference/`
```
git clone --depth 1 https://github.com/drhelius/Geargrafx.git reference/Geargrafx
git clone --depth 1 https://github.com/SingleStepTests/huc6280.git reference/huc6280-tests
mkdir reference/mednafen_src; cd reference/mednafen_src
curl -LO https://mednafen.github.io/releases/files/mednafen-1.32.1.tar.xz
tar -xJf mednafen-1.32.1.tar.xz mednafen/src/pce/pcecd.cpp mednafen/src/cdrom/scsicd.cpp mednafen/src/pce/pcecd.h
```

**When the references disagree:** Geargrafx remains the yardstick for the automatic tests. If a behavior
observed in Mednafen differs and Mednafen's code confirms it, we follow Mednafen and keep a compatibility
option only for the comparison tests against Geargrafx (example: `--gg-fader`).

## Known gaps

- **CD-ROM registers ($1800–$18FF), ADPCM and SCSI commands:** there is no reliable text document.
  The source is `reference/Geargrafx/src/cdrom*.cpp`, `scsi_controller*` and `adpcm*.cpp`. A summary of
  what is implemented (map, registers, SCSI phases, ADPCM) is in the headers of `runtime/cd/*.h`.
  The simulated console is a **standard** CD-ROM² (`gg_trace --bios` forces `GG_CDROM_STANDARD`; the
  Geargrafx default would be a Super CD-ROM², with 192 KB more RAM and a signature at $18C0).
- **Fine VDC details** (line timing, DMA, burst mode): `vdc.txt` is a summary; use `huc6270*`.
- **Archaic Pixels** (archaicpixels.com), the classic wiki, was offline on 2026-10-17.
